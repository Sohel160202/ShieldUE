# Support

## Questions and usage help

Use GitHub Discussions for questions about installation, Blueprint usage, C++ integration, and project architecture.

## Bug reports

Use the [bug report template](https://github.com/Sohel160202/ShieldUE/issues/new?template=bug_report.md). Include the ShieldUE commit, Unreal Engine version, platform, build configuration, and a minimal reproduction.

## Feature requests

Use the [feature request template](https://github.com/Sohel160202/ShieldUE/issues/new?template=feature_request.md). Explain the problem, proposed API, and expected security or performance impact.

## Security reports

Do not publish exploitable security details in a public issue. Follow [SECURITY.md](SECURITY.md).
