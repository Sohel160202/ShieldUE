# Code of Conduct

ShieldUE is a technical project intended to help Unreal Engine developers learn about runtime integrity and build more resilient gameplay systems.

Participants are expected to:

- Be respectful and constructive.
- Focus criticism on code, documentation, and ideas rather than people.
- Provide evidence when reporting technical problems.
- Avoid publishing private information or unverified security claims.
- Help keep discussions welcoming to developers at different experience levels.

Harassment, personal attacks, discrimination, spam, and deliberate publication of sensitive security information are not acceptable.

Project maintainers may remove content or restrict participation when necessary to keep the project safe and constructive.
